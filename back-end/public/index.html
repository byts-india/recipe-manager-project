API Reference

Clean, RESTful endpoints
ready in minutes

Explore the core endpoints. Full OpenAPI spec available in the docs portal.

GET

/v1/recipes

List and search recipes with filters for cuisine, diet, time, and more.

GET

/v1/recipes/{id}

Retrieve a single recipe with full details, steps, and nutritional data.

POST

/v1/recipes/search

Semantic search — find recipes by description or ingredients you have.

GET

/v1/recipes/{id}/nutrition

Detailed nutritional breakdown per serving: macros, vitamins, allergens.

POST

/v1/substitutions

Get ingredient substitutions with quantity ratios and flavour notes.

POST

/v1/meal-plans

Generate a weekly meal plan by calories, budget, or dietary preference.

GET

/v1/cuisines

Browse all 45+ supported cuisine types with region metadata.

DEL

/v1/saved/{id}

Remove a recipe from a user's saved collection (user-scoped tokens).

FAQ

Common questions

Can't find what you're looking for? Reach out to our team.

Do I need a credit card to start?

No. The Starter plan is completely free and requires only an email address to sign up. You'll only enter billing details if you upgrade.

How do I authenticate requests?

Pass your API key as a Bearer token in the Authorization header. Keys are generated instantly in the dashboard.

What happens if I exceed my limit?

Requests return a 429 Too Many Requests response. You can upgrade any time or purchase add-on bundles without downtime.

Is the data updated regularly?

Yes — our culinary team adds hundreds of new recipes weekly, and nutritional data is synced with the USDA FoodData Central database monthly.

Can I use Recipe API in a commercial product?

Absolutely. All paid plans include a commercial use license. Attribution is appreciated but not required.

Do you offer SDKs?

We provide official SDKs for Node.js, Python, Ruby, and PHP. Community SDKs exist for Go, Rust, and Swift — all linked in the docs.
